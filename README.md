# JS Training (Excel Application)

Чистий JavaScript додаток для роботи з таблицями (аналог Excel).

## Режими роботи

Проект підтримує два основних режими розробки:

1.  **Development (Розробка)**
    *   **Команда:** `npm run start`
    *   **Особливості:**
        *   Запуск локального сервера за адресою `http://localhost:3000`.
        *   **Hot Module Replacement (HMR):** миттєве оновлення сторінки при зміні коду.
        *   **Source Maps:** полегшене налагодження коду в браузері.
        *   Файли збираються в оперативній пам'яті для максимальної швидкості.

2.  **Production (Продакшн)**
    *   **Команда:** `npm run build`
    *   **Особливості:**
        *   Повна мініфікація JavaScript, CSS та HTML.
        *   Оптимізація коду для швидкого завантаження.
        *   Створення фізичних файлів у папці `dist`.
        *   Додавання хешів до назв файлів для коректного кешування браузером.

## Використані Webpack плагіни

Для автоматизації збірки використовуються наступні інструменти:

*   **CleanWebpackPlugin**: Автоматично очищує папку `dist` перед кожною новою збіркою, щоб там не залишалося старих файлів.
*   **HtmlWebpackPlugin**: Генерує файл `index.html` на основі шаблону та автоматично підключає туди всі зібрані скрипти та стилі.
*   **CopyPlugin**: Використовується для копіювання статичних ресурсів (наприклад, `favicon.ico`) безпосередньо у вихідну папку.
*   **MiniCssExtractPlugin**: Виділяє CSS-код в окремі файли (замість вбудовування в JS), що покращує продуктивність завантаження.
*   **ESLintPlugin**: Автоматично перевіряє якість коду під час розробки та збірки відповідно до налаштованих правил.

## Технологічний стек

*   **JavaScript (ES6+)**: Сучасний стандарт мови.
*   **Babel**: Транспіляція коду для підтримки старих браузерів.
*   **Sass**: Використання препроцесора для зручної роботи зі стилями.
*   **ESLint**: Статичний аналіз коду для запобігання помилкам.
